# sAIfer Lab Cybersecurity Website

A custom Jekyll and Sveltia CMS template for the sAIfer Lab Cybersecurity and
Artificial Intelligence Research Group.

The public website provides About Us, Thesis, and Rules pages. Researchers can
manage site settings, macroareas, page content, and thesis topics through
Sveltia CMS at `/admin/`.

See [INSTALL.md](INSTALL.md) for deployment instructions.
